# 별화묘원 리소스팩

본 저장소는 별화묘원 서버 리소스팩 배포를 위한 저장소입니다.

## 이용 허가

이 리소스팩은 별화묘원 서버뿐만 아니라 다른 Minecraft 서버, 싱글플레이 및 개인 환경에서도 원본 형태 그대로 사용할 수 있습니다.

별화묘원 서버 외부에서 사용하는 경우에도 별도의 허가는 필요하지 않습니다.

## 이용 제한

다음 행위는 허용되지 않습니다.

- 리소스팩 및 내부 자산의 무단 수정 또는 변형
- 리소스팩 전체 또는 일부의 무단 재배포 및 재업로드
- 리소스팩 내부 자산을 추출하여 다른 리소스팩이나 콘텐츠에 사용하는 행위
- 제작자 또는 저작권 정보를 허위로 표시하거나 제거하는 행위

리소스팩을 다른 사람에게 안내할 때에는 파일을 직접 재배포하지 말고 이 저장소의 링크를 공유해 주세요.

모든 저작권과 사용 권한은 별화묘원 운영 측 및 각 원저작자에게 있습니다.
